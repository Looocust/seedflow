# T-003 · Reglas de dependencias

## Qué logra
`checks/dependencias.py` detecta las reglas de dependencias del spec (§Reglas ›
Dependencias). Ninguna tiene arreglo mecánico.

## Criterios de aceptación
- [ ] Una `lib-python-*` sin `@<sha>` o con `@main` en `layers/requirements.txt` o `python/requirements.txt` es importante (−10), con la línea exacta
- [ ] La misma librería con SHAs distintos entre `layers/` y `python/requirements.txt` es menor (−3)
- [ ] Un import de una librería Melonn (`melonn*`, `we_are_melonn.*`) cuyo repo no está en el `layers/requirements.txt` de ese microservicio es importante (−10); la tabla import → repo sale de `references/librerias.md`
